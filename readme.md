# Минималистичное приложение To-Do со сворачивающимся виджетом
![GitHub Created At](https://img.shields.io/github/created-at/FantasmaDux/SimpleToDoApp?color=bright-green&style=flat-square)


Приложение позволяет создавать, редактировать, удалять и просматривать выполненные задачи. Есть возможность указать крайний срок выполнения. Есть виджет, который можно свернуть и развернуть. Всё. Никаких 30 различных подтем, никаких календарей, никаких бесконечных уведомлений. Минимализм.
